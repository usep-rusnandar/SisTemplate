# Panduan pengguna (end user)

Dua dokumen terpisah — audiens berbeda. Jangan menggabungkan atau mengedarkan keduanya ke pihak yang sama.

| Dokumen | Audiens | Isi | Format |
|---|---|---|---|
| [Panduan PIC Vendor — Vendor Workspace](./panduan-pengguna-vendor-workspace.html) | PIC mitra vendor saja | Portal Workspace: undangan, akun, wizard 5 langkah, submit, revisi, e-sertifikat. Tanpa rantai persetujuan internal. | HTML siap cetak / PDF |
| [Panduan Internal — Vendor Onboarding](./panduan-pengguna-vendor-onboarding.html) | Pegawai SIS (Officer, Dept Head, Division Head, Super Admin) | SSO, peran, kode status, undang/tinjau/setujui/daftarkan, impor. **Jangan dikirim ke vendor.** | HTML siap cetak / PDF |

Cara memakai:

1. Buka berkas `.html` di Chrome atau Edge.
2. Cetak ke PDF (File → Print → Save as PDF) jika akan diedarkan.
3. Kirim **hanya** panduan Workspace ke PIC vendor. Kirim panduan Onboarding lewat kanal internal.

Jangan mengedit isi teknis tanpa menyesuaikan aplikasi (versi 1.0.0).
